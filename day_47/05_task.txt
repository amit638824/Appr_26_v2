Express.js – API Routing Practice Tasks

Topic: Express.js Routing, Request Body, Query Parameters & URL
Parameters

Instructions 1. Create an Express.js server. 2. Use port 8000. 3. Import
Express and initialize the application. 4. Use express.json()
middleware. 5. Create separate and unique URLs for every API. 6. Use the
correct request property according to the task: - req.body – POST
requests - req.query – GET requests - req.params – DELETE requests 7.
Send the received data using res.send(). 8. Do not use any database. 9.
Complete all tasks using Express.js only.

IMPORTANT API STRUCTURE

Method: POST Request Property: req.body Total Tasks: 30

Method: GET Request Property: req.query Total Tasks: 30

IMPORTANT NOTES - Every API must have a unique URL. - POST requests must
receive data through req.body. - GET requests must receive data through
req.query. - DELETE requests must receive data through req.params. - Use
res.send() to return the received data. - Do not use MongoDB, MySQL, or
any other database. - Write all API routes inside a single Express.js
server file. - Students must write the complete code themselves without
copying solutions.
