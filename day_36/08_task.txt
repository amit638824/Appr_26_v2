## Common Instructions for All Tasks

1. Use React functional components.
2. Use Redux Toolkit for state management.
3. Create separate slice files.
4. Each slice must contain at least two reducers.
5. Use `action.payload` wherever data needs to be passed.
6. Use `useDispatch()` to dispatch actions.
7. Use `useSelector()` to access Redux state.
8. Use controlled forms wherever form input is required.
9. Display submitted data in tables wherever applicable.
10. Implement proper validation for forms.
11. Add Delete, Update or Clear functionality wherever required.
12. Combine all reducers in `rootReducer.js`.
13. Configure the Redux store in `store.js`.
14. Connect Redux Provider in `main.jsx`.

**Final Goal:** Build one complete Redux Toolkit practice project containing all 15 slices with working forms, tables, buttons, validation and state management.
