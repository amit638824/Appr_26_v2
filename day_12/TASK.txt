INSTRUCTIONS
------------

1. Create HTML forms for the given validation tasks.
2. Use JavaScript to validate all form fields.
3. Use Regular Expressions (RegEx) wherever mentioned.
4. Display an appropriate error message when the input is invalid.
5. Display a success message when all required inputs are valid.
6. Do not use HTML5 validation attributes such as required, pattern, or
   minlength for the main validation logic.
7. Complete all tasks before the next class.
