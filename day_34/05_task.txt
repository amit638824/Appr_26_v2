============================================================
IMPORTANT CONCEPTS TO REMEMBER
============================================================

1. useLayoutEffect runs after React updates the DOM and before
   the browser paints the screen.

2. useLayoutEffect(() => { ... }, [])
   Runs when the component mounts (with a development StrictMode
   caveat).

3. useLayoutEffect(() => { ... }, [count])
   Runs after the initial mount and again when count changes.

4. useLayoutEffect(() => { ... })
   Runs after every render.

5. useRef is useful when you need to access an HTML element
   directly, such as an input, heading, or div.

6. Use useLayoutEffect mainly for work that must happen before
   the browser paints, such as measuring an element and making
   a layout adjustment. For most other side effects, useEffect
   is the better choice.
