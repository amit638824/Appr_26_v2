============================================================ IMPORTANT
MONGODB VALIDATION CONCEPTS
============================================================

Practice and understand these concepts while completing the tasks:

1.  db.createCollection() – Create a collection with options.
2.  validator – Add validation rules to a collection.
3.  $jsonSchema – Define a JSON Schema validator.
4.  bsonType – Specify MongoDB BSON data types.
5.  required – Specify fields that must be present.
6.  properties – Define rules for document fields.
7.  additionalProperties – Control whether extra fields are allowed.
8.  enum – Restrict a field to a list of allowed values.
9.  minimum and maximum – Set numeric limits.
10. validationLevel – Control when validation is applied.
11. validationAction – Choose whether invalid writes are rejected or
    warned.
12. collMod – Modify validation rules on an existing collection.

NOTE: MongoDB schema validation checks documents when they are inserted
or updated. It does not automatically add missing fields or convert
values to the required BSON types. Use the correct BSON types when
inserting documents. For example, use NumberInt(25) for an int and
NumberDecimal(“25.5”) or an appropriate double value for a double,
according to the schema.
