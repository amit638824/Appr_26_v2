EXPRESS.JS PRACTICE TASKS 40 EASY TASKS – GET & POST METHODS Topic:
Array of Objects | Express.js | GET | POST | req.body | Array Methods

============================================================ GENERAL
INSTRUCTIONS
============================================================

1.  Create a separate Express.js practice project.
2.  Use an array of objects to store data.
3.  Use only GET and POST HTTP methods.
4.  Use express.json() to receive JSON data in POST requests.
5.  Test every API using Postman.
6.  Do not use MongoDB or any other database.
7.  Use port 5000.
8.  For POST tasks, add the new object to the existing array.
9.  For GET tasks involving a single record or filtering, use suitable
    array methods.
10. Return responses in JSON format.

============================================================ SECTION 1:

============================================================

============================================================ IMPORTANT
NOTES ============================================================

1.  Use let when declaring arrays that will be modified with push().
2.  Use req.params to read values from URL parameters.
3.  Use req.body to read data sent in POST requests.
4.  Use find() to get one matching object from an array.
5.  Use filter() to get multiple matching objects from an array.
6.  Use push() to add a new object to an array.
7.  Remember that array data is stored only in memory. It resets when
    the server restarts.
8.  Complete the tasks in order, starting from Task 1.
