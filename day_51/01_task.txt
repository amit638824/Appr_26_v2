GENERAL INSTRUCTIONS 
1. Create a separate schema and model for every task. 
2. Use Express.js and Mongoose for all APIs. 
3. Connect every task to the same MongoDB database: mongodb://localhost:27017/crud 
4. Use express.json() middleware to read JSON request bodies. 
5. Create all four CRUD APIs for every task: POST, GET, DELETE, and PUT. 
6. Use req.body for POST and PUT data. 
7. Use req.params to receive the MongoDB _id for DELETE and PUT. 
8. Use .save() for POST, .find() for GET, findByIdAndDelete() for DELETE,
 and findByIdAndUpdate() with $set for PUT. 
9. Use unique kebab-case URLs exactly as listed. 10. Every schema
must contain the five listed fields. MongoDB will generate the _id
automatically. 11. Test every API using Postman. Return suitable success
and error responses.

COMMON EXPRESS SETUP - Import express and mongoose. - Create an Express
app. - Add app.use(express.json()). - Connect to
mongodb://localhost:27017/crud. - Run the server on port 8000. - Create
separate schema/model definitions and API routes for each task.
