Important – React Practice Tasks

1.  Use Redux Toolkit for all 15 slices.
2.  Each slice must have at least 2 reducers.
3.  Use action.payload wherever data needs to be passed.
4.  Export all actions and reducers correctly.
5.  Do not copy solutions.
6.  After completing all slices, combine them in rootReducer.js and
    configure your Redux store.


REDUX TOOLKIT PRACTICE PROJECT 15 SLICES — BASIC, INTERMEDIATE &
ADVANCED

============================================================ PART 1:
BASIC SLICES
============================================================

TASK 1 — productSlice.js Create a product management slice.

Requirements: - Create an initialState with products (empty array) and
totalProducts (0). - Create a slice named product. - Add addProduct to
add a new product. - Add removeProduct to remove a product using its
ID. - Export both actions and the reducer.

TASK 2 — cartSlice.js Create a shopping cart slice.

Requirements: - Create an initialState with cartItems (empty array) and
totalQuantity (0). - Create a slice named cart. - Add addToCart to add
an item. - Add removeFromCart to remove an item using its ID. - Export
both actions and the reducer.

TASK 3 — todoSlice.js Create a todo management slice.

Requirements: - Create an initialState with todos (empty array). -
Create a slice named todo. - Add addTodo to add a new task. - Add
deleteTodo to delete a task using its ID. - Export both actions and the
reducer.

TASK 4 — counterSlice.js Create a counter slice.

Requirements: - Create an initialState with count set to 0. - Create a
slice named counter. - Add increment to increase the count by 1. - Add
decrement to decrease the count by 1. - Export both actions and the
reducer.

TASK 5 — profileSlice.js Create a user profile slice.

Requirements: - Create an initialState with name, email, and phone. -
Create a slice named profile. - Add updateProfile to update profile
information. - Add clearProfile to reset the profile. - Export both
actions and the reducer.
