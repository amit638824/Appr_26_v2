MongoDB – Practical Assignment (50 Questions)

Database: company
Collection: users
Total Sets: 10
Questions per Set: 5
Total Questions: 50
Platform: MongoDB Shell (mongosh)

Instructions
1. Solve all questions using MongoDB Shell (mongosh).
2. Use database name company and collection name users.
3. Insert at least 15 users' records before starting.
4. Create suitable array fields, nested documents and different BSON data types.
5. Write queries yourself. Do not copy solutions.
6. Execute every query and verify its output.
7. Take a screenshot of every executed query along with its output.
8. Paste each screenshot below its respective question in MS Word.

SET 1 – Array Size Operator $size (1–5)
1. Find all users whose skills array contains exactly 3 elements using $size.
2. Find all users whose skills array contains exactly 4 elements using $size.
3. Find all users whose subjects array contains exactly 5 elements using $size.
4. Find all users whose hobbies array contains exactly 2 elements using $size.
5. Find all users whose projects array contains exactly 3 elements using $size.

SET 2 – BSON Type Operator $type (6–10)
6. Find all users whose age field has a number type using $type.
7. Find all users whose name field has a string type using $type.
8. Find all users whose skills field has an array type using $type.
9. Find all users whose createdAt field has a date type using $type.
10. Find all users whose salary field has a double type using $type.

SET 3 – Array Operator $all (11–15)
11. Find all users whose skills array contains both HTML and CSS using $all.
12. Find all users whose skills array contains both JavaScript and React using $all.
13. Find all users whose subjects array contains both Maths and English using $all.
14. Find all users whose hobbies array contains both Cricket and Music using $all.
15. Find all users whose skills array contains HTML, CSS and JavaScript using $all.

SET 4 – Element Match Operator $elemMatch (16–20)
16. Find all users whose marks array contains a subject with score greater than 80 using $elemMatch.
17. Find all users whose marks array contains a subject named Maths with score greater than 70.
18. Find all users whose projects array contains a project with status Active and duration greater than 3 months.
19. Find all users whose exams array contains a subject with marks greater than 60 and less than 90.
20. Find all users whose experience array contains a company with experience greater than 2 years.

SET 5 – Expression Operator $expr (21–25)
21. Find all users whose salary is greater than their bonus using $expr.
22. Find all users whose age is greater than their minimumAge field using $expr.
23. Find all users whose salary is equal to their monthlyIncome field using $expr.
24. Find all users whose salary is greater than 30000 and whose bonus is greater than 5000 using $expr.
25. Find all users whose total salary and bonus is greater than 50000 using $expr.

SET 6 – Regular Expression $regex (26–30)
26. Find all users whose name starts with the letter A using $regex.
27. Find all users whose name ends with the letter a using $regex.
28. Find all users whose city contains the word Luck using $regex.
29. Find all users whose email ends with gmail.com using $regex.
30. Find all users whose department starts with the letter I using $regex with case-insensitive option.

SET 7 – JSON Schema Validation $jsonSchema (31–35)
31. Create a JSON Schema that requires name, age and email fields.
32. Create a JSON Schema where name must be a string and age must be an integer.
33. Create a JSON Schema where salary must be a number and skills must be an array.
34. Create a JSON Schema where department must be a string and its value must be one of HR, IT or Finance.
35. Create a collection named employees with JSON Schema validation requiring name, age, email, salary and department.

SET 8 – Projection Operator $project (36–40)
36. Display only the name, age and city fields using $project.
37. Display the name and salary fields while hiding _id using $project.
38. Display the name, department and email fields using $project.
39. Display only the first two elements of the skills array using $project and $slice.
40. Create a new field named annualSalary by multiplying monthly salary by 12 using $project.

SET 9 – Mixed Operators (41–45)
41. Find users whose skills array contains exactly 3 elements and includes React.
42. Find users whose age field has number type and whose salary is greater than 30000.
43. Find users whose marks array contains a subject named English with marks greater than 75 using $elemMatch.
44. Find users whose name starts with R and whose department is IT.

SET 10 – Advanced Practical Queries (46–50)

48. Display users whose name starts with A, showing only name, email and department using $regex and $project.
