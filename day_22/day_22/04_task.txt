REACT API TABLE PRACTICE — 20 TASKS
====================================

GENERAL INSTRUCTIONS
--------------------
1. Create a React functional component for each task.
2. Use the provided API URL to fetch data. Do not hardcode API data.
3. Use Bootstrap classes to create a responsive table.
4. Use the .map() method to display each object as a table row.
5. Use a unique key for each row.
6. Display the specified object properties in separate table columns.
7. If the API provides an image URL, display it using an <img> tag with a suitable height and width.
8. Display a meaningful heading above the table.
9. Display a loading message while data is being fetched.
10. Handle errors using .catch() or try...catch.
11. Use array methods such as .filter(), .find(), .reduce(), .sort(), .slice(), .some(), .every(), .includes(), .findIndex(), and .forEach() wherever appropriate to the task.
12. Use .length to display the total number of records where required.
13. Use optional chaining (?.), nullish coalescing (??), template literals, and the spread operator (...) where appropriate.
14. Keep the code clean, readable, and properly structured.
15. Do not force every array method into every task. Use the methods relevant to the requirements.
