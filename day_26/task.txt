INSTRUCTIONS

1. Read each task carefully and write the complete code.
2. Use React functional components.
3. Import and use "useRef" from React wherever required.
4. Use props to pass data from Parent Component to Child Component.
5. Practice Props Drilling by passing data through multiple component levels.
6. Keep separate components inside the "components" folder when appropriate.
7. Use "ref.current" to access DOM elements and input values.
8. Use "useEffect()" with useRef wherever DOM manipulation after rendering is required.
9. Use Bootstrap classes for forms, buttons, cards, and layouts wherever required.
10. Run the project and test every task in the browser. Check the console wherever console.log() is used.

Create a complete React Profile Management application with the following requirements:

- Create "App.jsx", "ProfileForm.jsx", "CustomInput.jsx", and "Profile.jsx".
- Create Name, Email, and Phone input fields.
- Create separate refs using "useRef()" for all three input fields.
- Pass refs from App.jsx to ProfileForm.jsx through props.
- Pass refs further to CustomInput.jsx where required.
- Use props drilling between App, ProfileForm, and CustomInput.
- Read Name, Email, and Phone values when the Submit button is clicked.

- Display the submitted profile information inside a Bootstrap card.
