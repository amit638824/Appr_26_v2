COMPLETE NOTES: EXTERNAL CSS IN REACT
================================================================================

1. What is External CSS?

External CSS means writing CSS in a separate .css file and importing
that file into a React component.

Example:

App.jsx

import “./App.css”;

function App() { return (
Hello React
); }

export default App;

App.css

.heading { color: green; font-size: 28px; text-align: center; }

The JSX file contains the structure/content and the CSS file contains
the styling.

2. Why use External CSS?

-   Keeps JSX code clean.
-   Keeps CSS separate from JavaScript.
-   Makes styling easier to manage.
-   Allows CSS classes to be reused.
-   This is a common way to style React applications.

3. Importing CSS

Write this at the top of App.jsx:

import “./App.css”;

The file name and path must be correct.

4. className in React

HTML normally uses:

class=“heading”

React uses:

className=“heading”

Example:

Welcome
CSS:

.heading { color: blue; }

5. Important CSS Properties

color

Changes the text color.

Example: color: red;

font-size

Changes the size of text.

Example: font-size: 30px;

text-align

Controls horizontal text alignment.

Example: text-align: center;

font-style

Changes the style of text.

Example: font-style: italic;

6. Basic External CSS Pattern

App.jsx:

import “./App.css”;

function App() { return (
      <h1 className="title">My Heading</h1>
      <p className="text">My paragraph</p>
    </div>

); }

export default App;

App.css:

.box { text-align: center; }

.title { color: green; font-size: 30px; }

.text { color: #555; font-style: italic; }

7. JSX and CSS Connection

The connection happens in two steps:

Step 1: Import the CSS file.

import “./App.css”;

Step 2: Use className.

Hello
Then App.css finds .title and applies the styling.

COMMON ERROR REVISION
================================================================================

ERROR 01: Wrong CSS import

Wrong:

import “App.css”;

Correct:

import “./App.css”;

Reason: “./” tells React to look for App.css in the current folder.

ERROR 02: Using class instead of className

Wrong:

Hello
Correct:

Hello
Reason: React JSX uses className instead of class.

ERROR 03: CSS class selector missing dot

Wrong:

title { color: red; }

Correct:

.title { color: red; }

Reason: A CSS class selector starts with a dot.

ERROR 04: Wrong CSS property spelling

Wrong:

font-sizee: 30px;

Correct:

font-size: 30px;

ERROR 05: Missing semicolon

Wrong:

color: red

Correct:

color: red;

ERROR 06: CSS class name does not match JSX

JSX:

Hello
CSS:

.title { color: blue; }

Problem: The JSX uses heading but CSS uses title.

Correct:

.heading { color: blue; }

ERROR 07: Forgetting to import CSS

If App.jsx contains className but App.css is not imported, the external
CSS may not be applied.

Correct:

import “./App.css”;

ERROR 08: Wrong file name

If the file is named App.css, write:

import “./App.css”;

Do not write:

import “./app.css”;

on systems where file names are case-sensitive.

ERROR 09: Wrong JSX closing tag

Wrong:

Hello
Correct:

Hello
ERROR 10: Forgetting to export App

Correct:

export default App;

ERROR 11: Putting CSS inside App.jsx

For this practice, do not put the CSS rules inside App.jsx.

Keep:

App.jsx

React/JSX code

App.css

CSS code

ERROR 12: Using inline CSS

Do not use this for these projects:

Use:

Hello
and App.css:

.title { color: red; }
