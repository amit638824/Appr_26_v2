TOPIC 1: LOCAL STORAGE — Basic Operations (setItem, getItem, removeItem, clear)
================================================================================

Task 01
Store your name in localStorage using key "username" and value "Rahul" (or your name).
(Example: localStorage.setItem("username", "Rahul");)

Task 02
Retrieve the value of "username" from localStorage using localStorage.getItem() and print it using console.log().

Task 03
Update the "username" in localStorage with a new name (e.g. "Rohit") and print the updated value.

Task 04
Remove the item "username" from localStorage using localStorage.removeItem().

Task 05
Add two items to localStorage ("city": "Delhi" and "country": "India"). Then use localStorage.clear() to remove all data.

Task 06
Use localStorage.length to check and print how many items are currently stored in localStorage.

Task 07
Store a number 100 in localStorage with key "score". Retrieve it and convert it back to a number using Number(), then print the result.
(Hint: Values stored in localStorage are always strings.)

TOPIC 2: SESSION STORAGE — Basic Operations
================================================================================

Task 08
Store a message "Welcome" in sessionStorage using key "greeting".
(Example: sessionStorage.setItem("greeting", "Welcome");)

Task 09

Task 10
Store an item "sessionId" with value "12345" in sessionStorage, and then remove it using sessionStorage.removeItem().

Task 11
Store two items in sessionStorage ("tab": "1", "status": "active"). Then clear all data using sessionStorage.clear().

Task 12
Store user login status in sessionStorage using key "isLoggedIn" and value "true".
Retrieve it and use an if condition to print "User is logged in" if the value is "true".
