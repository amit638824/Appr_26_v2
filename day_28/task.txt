DAY 8 – REACT HOOK FORM + YUP VALIDATION
Practice Worksheet
Total Questions: 70
Total Sections: 7
Topics Covered: React Hook Form, Yup Validation, Image Upload, File Size Validation, Multiple Images, Form Reset, Error Handling, Real-World Forms.
General Instructions
1. Read each task carefully and write the complete React code.
2. Use React functional components.
3. Use useForm() from react-hook-form.
4. Use yup and yupResolver for form validation.
5. Use register() to connect inputs with React Hook Form.
6. Use handleSubmit() to validate and submit form data.
7. Use formState.errors to display individual error messages.
8. Use reset() to clear form values after submission or when the Reset button is clicked.
9. Import Bootstrap CSS and use Bootstrap classes for responsive layouts.
10. Display validation errors below their respective inputs using conditional rendering.
11. Use console.log() to display submitted form data wherever specified.
12. For image tasks, validate file type, maximum size and file count using Yup.
13. Show image previews wherever required and clean up object URLs when they are no longer needed.
14. Use accept on file inputs to guide file selection, but validate files in Yup and on the server as well.
15. Test every task in the browser with valid and invalid inputs.
