QUICK REVISION
==============

Promise States:
- Pending
- Fulfilled
- Rejected

Important Methods:
- then()
- catch()
- finally()
- Promise.resolve()
- Promise.reject()
- Promise.all()
- Promise.allSettled()
- Promise.race()
- Promise.any()

Important Rule:
- then() se value return karoge to next then() ko milegi.
- async function hamesha Promise return karta hai.
- await ke saath error handling ke liye try...catch use karo.
- Independent Promises ko parallel chalane ke liye Promise.all() useful hai.
- Partial results chahiye ho to Promise.allSettled() use karo.
- Sabse pehla settle result chahiye ho to Promise.race() use karo.
- Pehla successful result chahiye ho to Promise.any() use karo.
