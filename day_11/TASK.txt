TOPIC 7: ARRAY OF OBJECTS — READ THIS FIRST
================================================================================

An array of objects means one array, and each item inside it is an object.

Example:
  let students = [
    { name: "Alice", age: 22 },
    { name: "Bob", age: 25 },
    { name: "Charlie", age: 23 }
  ];

How to read one value:
  students[0]           → first object  { name: "Alice", age: 22 }
  students[0].name      → "Alice"
  students[2].age       → 23
  students.length       → 3  (total objects)

How to loop with forEach (very important):
  students.forEach(function (student) {
    console.log(student.name);
  });

forEach goes to every object one by one.
Inside the function, student is the current object.

You can also print more than one value:
  console.log(student.name, student.age);

Use a condition inside forEach to filter:
  students.forEach(function (student) {
    if (student.age > 22) {
      console.log(student.name);
    }
  });
