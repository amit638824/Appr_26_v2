TOPIC 3: ES MODULE — Single Export (export default)
================================================================================

Run ES Module files using Node.js.
To use ES Modules, add this in package.json:
    { "type": "module" }

Note: ES Module uses import / export.
Single export uses: export default functionName;
Import uses: import functionName from "./file.js";
Always use .js extension in the import path.

================================================================================
TOPIC 5: ES MODULE ALIASING — import { name as alias }
================================================================================

Note: Aliasing means importing a function/variable with a different name.
Syntax:
    import { add as sum } from "./math.js";
Now you will call sum(), not add().
